# @comnipl/miloa-plugin-contract

The data and protocol types that Miloa View plugins and the host share, and the protocol constants such as `PROTOCOL_FEATURES`, `PLUGIN_LIMITS`, and `RPC_ERROR_CODES`. [`@comnipl/miloa-plugin-sdk`](https://www.npmjs.com/package/@comnipl/miloa-plugin-sdk) depends on this package. Add it next to the SDK when a plugin imports these types or constants itself.

```sh
pnpm add @comnipl/miloa-plugin-contract
```
