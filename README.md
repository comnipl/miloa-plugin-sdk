# Miloa Plugin SDK

Build View plugins for Miloa with `@comnipl/miloa-plugin-sdk` and `@comnipl/miloa-plugin-contract`. This repository mirrors the source maintained in the Miloa repository.

## Documentation

- [llms.txt](https://developers.miloa.io/llms.txt)
- [Getting started](https://developers.miloa.io/plugins/getting-started.md)
- [Concepts](https://developers.miloa.io/plugins/concepts.md)
- [Reference](https://developers.miloa.io/plugins/reference.md)
- [Upload a plugin](https://developers.miloa.io/plugins/upload.md)
